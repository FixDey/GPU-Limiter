# GPU Limiter

![Windows](https://img.shields.io/badge/Windows-10%201809%2B%20x64-0078D6?logo=windows)
![.NET](https://img.shields.io/badge/.NET-8-512BD4?logo=dotnet)
![WinUI 3](https://img.shields.io/badge/UI-WinUI%203-0078D4)

**Приложение для Windows, которое «притормаживает» мощную видеокарту до уровня более слабой:** снижает частоты ядра и памяти, лимит мощности и объём доступной видеопамяти. Нужно, чтобы проверить, как игра, программа или собственная разработка поведёт себя на бюджетном или старом железе, не имея этого железа под рукой.

*English: a Windows tool that throttles a GPU (core/memory clocks, power limit, available VRAM) to approximate a weaker card for testing.*

## Возможности

- **Профили 112 видеокарт** (NVIDIA, AMD, Intel Arc): выбираете, какую карту хотите изобразить, и программа сама подбирает проценты, лимит мощности и объём VRAM. Профили хранят относительную производительность (RTX 2060 = 100), пропускную способность памяти, объём VRAM и TDP.
- **Ручная настройка:** ползунок производительности (% от вашей карты) и точное поле для объёма видеопамяти.
- **Ограничение по отдельности:** частота ядра, частота памяти, лимит мощности, видеопамять. Каждый пункт включается и выключается галочкой.
- **Предпросмотр:** до нажатия кнопки видно, какие именно значения будут выставлены.
- **Живая телеметрия** раз в секунду: частоты, мощность, загрузка, температура, использование VRAM.
- **Сброс одной кнопкой** и необязательный автосброс при закрытии программы.
- Журнал действий, тёмная и светлая темы, русский интерфейс.

## Что поддерживается

| | Частота ядра | Частота памяти | Лимит мощности | Лимит VRAM | Телеметрия |
|---|:-:|:-:|:-:|:-:|:-:|
| **NVIDIA** | да | да | да | да (CUDA, запасной вариант OpenCL) | полная |
| **AMD** | нет | нет | нет | да (OpenCL) | только VRAM |
| **Intel Arc** | нет | нет | нет | да (OpenCL) | только VRAM |

У AMD и Intel в Windows нет публичного API для частот и лимитов мощности. Их меняйте в Adrenalin или Intel Graphics Software, а GPU Limiter возьмёт на себя ограничение видеопамяти.

Если драйвер конкретной NVIDIA-карты не поддерживает какой-то из параметров, соответствующий пункт в окне помечается как «недоступно».

## Как это работает

| Параметр | Как ограничивается |
|---|---|
| Частота ядра | `nvidia-smi -lgc`: максимум берётся как процент от штатного, значение подгоняется под поддерживаемые картой частоты |
| Частота памяти | `nvidia-smi -lmc`: по отношению пропускных способностей целевой и вашей карты (или по ползунку, если профиль не выбран) |
| Лимит мощности | `nvidia-smi -pl`: TDP целевой карты, в пределах допустимого для вашей |
| Видеопамять | программа занимает «лишнюю» VRAM служебными буферами через CUDA или OpenCL, оставляя приложениям заданный объём |
| Сброс | `-rgc`, `-rmc`, возврат штатного лимита мощности, освобождение буферов VRAM |

## Важно знать

- Это **приближение**, а не точная эмуляция. Архитектура, количество блоков, кэш и поддержка технологий остаются от вашей карты. Значения в профилях ориентировочные.
- Название и идентификатор видеокарты **не подменяются**: игры и бенчмарки по-прежнему видят вашу настоящую карту.
- Профиль не подбирается автоматически для ноутбучных видеокарт (Laptop, Max-Q, Mobile). Для них задайте процент ползунком.
- Нужны **права администратора**: без них `nvidia-smi` не применит лимиты. Ярлык и exe запрашивают UAC сами.
- Лимиты действуют, пока вы их не сбросите. Если программа закрылась аварийно, нажмите «Сбросить всё» при следующем запуске или запустите `nvidia-smi -rgc`, `nvidia-smi -rmc`. Перезагрузка тоже возвращает штатные значения.
- Вы используете программу на свой риск. Программа только **снижает** частоты и лимит мощности.

## Требования

- Windows 10 версии 1809 или новее, 64-разрядная
- Права администратора
- Драйверы видеокарты. Для частот и мощности NVIDIA нужен `nvidia-smi` (идёт с драйвером), для ограничения VRAM на AMD и Intel нужен `OpenCL.dll` (идёт с драйвером)
- Установка .NET или Windows App SDK **не требуется**: всё упаковано в программу (self-contained)

## Установка

Скачайте `GpuLimiter_Setup.exe` из раздела [Releases](../../releases) и запустите. Установщик поставит программу в `C:\Program Files\GPU Limiter`, создаст ярлыки на рабочем столе и в меню «Пуск» и добавит запись в «Установка и удаление программ».

Установщик не подписан цифровой подписью, поэтому SmartScreen может предупредить о неизвестном издателе: «Подробнее → Выполнить в любом случае».

## Использование

1. **Моя видеокарта** — выберите карту, если их несколько.
2. **Под какую видеокарту замаскироваться** — выберите профиль или «Свой процент (ползунок)». Ползунок и объём VRAM подстроятся сами, их можно поправить вручную.
3. **Что ограничивать** — отметьте нужные пункты.
4. Нажмите **«Применить ограничения»**. Состояние видно в строке телеметрии и в журнале.
5. Когда тест окончен, нажмите **«Сбросить всё»** либо просто закройте программу, если включён автосброс.

## Сборка из исходников

Нужны Windows 10/11 x64 и [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). Visual Studio не обязательна.

```bat
dotnet publish -c Release -r win-x64
```

Готовая программа окажется в `bin\Release\net8.0-windows10.0.19041.0\win-x64\publish\`. Можно и просто запустить `build.bat`.

Установщик собирается из этой папки с помощью [NSIS](https://nsis.sourceforge.io/): скопируйте содержимое `publish` в папку `payload` рядом с `GpuLimiter.nsi` и выполните `makensis GpuLimiter.nsi`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Core.cs` | база профилей, определение видеокарт, расчёт плана ограничений |
| `Nvidia.cs` | работа с `nvidia-smi`: запрос параметров, лимиты, сброс, телеметрия |
| `Dxgi.cs` | список видеоадаптеров и использование VRAM через DXGI (Vortice) |
| `Reservers.cs` | резервирование видеопамяти через CUDA и OpenCL |
| `MainWindow.xaml(.cs)` | интерфейс |
| `Program.cs`, `App.xaml(.cs)` | точка входа и приложение |
| `app.manifest` | запрос прав администратора |
| `GpuLimiter.nsi` | скрипт установщика |

## Технологии

C# / .NET 8, WinUI 3 (Windows App SDK 1.7, unpackaged, self-contained), [Vortice.DXGI](https://github.com/amerkoleci/Vortice.Windows), `nvidia-smi`, CUDA Driver API и OpenCL через P/Invoke.
